# Evaluation Plan

## Vision
- Image-level AUROC or another justified image-level metric
- Pixel-level localization metric if masks are produced
- False positives and false negatives
- AMD inference latency and throughput

## Sensors
- Detection of injected faults within expected time windows
- Detection delay from configured fault onset
- False alerts during baseline periods
- Reproducibility across scenario replays

## End-to-end
- Time from inspection event to visible alert
- Percentage of explanations with evidence references and manual citations
- Successful scenario replay rate
- Small operator-task timing test if feasible

Publish exact dataset splits, thresholds, hardware, software versions, run counts, and caveats with any reported numbers.
