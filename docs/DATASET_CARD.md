# Dataset Card — Draft

## Candidate
MVTec AD industrial anomaly-detection dataset.

Official page: https://www.mvtec.com/company/research/datasets/mvtec-ad

## Planned use
Select one category for the first computer-vision demo. Train on normal images and evaluate on normal/anomalous test images using the official split protocol where feasible.

## Provenance and licensing
Check the current official licence and attribution requirements before use. Do not commit the dataset itself unless redistribution is permitted. Record download date, category, split, file counts, preprocessing, and any deviations.

## Important limitation
MVTec images are not paired with this project's synthetic sensor telemetry. The sensor time series and event relationships are simulated for demonstration and must be labelled as such.
